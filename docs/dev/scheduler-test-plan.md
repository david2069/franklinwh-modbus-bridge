# Scheduler test plan

The input for the Scheduler test phase. Every behaviour documented in
[User Guide → Scheduler](../user/scheduler/index.md) carries a hidden marker in the page
source with its code location, its current test (or *untested* / *unclear*) and whether it
can write to a battery. The table below is generated from those markers.

## How to read it

| Column | Meaning |
|---|---|
| **#** | Behaviour id. The prefix names the page: CON concepts, TRG triggers, CND/SEN conditions, ACT/HAA actions, TGT targets, EXT exit, PRI priorities, OUT outcomes, RST/CLK restarts and clock, IDX overview. |
| **Risk** | **high**: can write to a battery and no test covers it (or the code is unclear). **medium**: can write to a battery but is tested, or cannot write but is untested or unclear. **low**: cannot write and is tested. |
| **Code** | File and lines under `src/franklinwh_bridge/`. |
| **Current test** | The unit test that covers it, or **untested** / **unclear** (the code is ambiguous or looks wrong; the test decides). |
| **Proposed test** | **unit**: pytest with the fake handlers in `tests/unit/test_scheduler*.py`. **unit (API)**: an httpx test against the router. **browser**: Playwright against a throwaway bridge. **VM/mock**: a throwaway bridge with a mock gateway. |
| **Battery write** | Whether the behaviour decides if, when or how a command reaches a battery. |

The table is ordered by risk, then *unclear* before *untested* before *tested*.

!!! danger "Test safely"
    Battery-write tests run against a **mock gateway** on a throwaway bridge, never a real
    aGate and never the owner's live bridge. *unclear* rows marked as likely defects should be
    written as tests that state the expected behaviour and fail today; fixes come after.

## Regenerate

```bash
python docs/dev/_gen_test_plan.py          # rewrite the table below
python docs/dev/_gen_test_plan.py --check  # non-zero if out of date or a marker is malformed
```

Marker format, one HTML comment next to the documented text:

```html
<!-- @b TRG-04 ;; src: gateway/scheduler.py:120-138 ;; tested: tests/unit/test_scheduler.py::test_inactive_outside_window ;; write: yes ;; b: what the code does ;; test: the test to add -->
```
